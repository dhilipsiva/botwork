# Usability study kit

The kit for the usability sessions of [roadmap decision D2](../docs/decisions.md#d2-usability-sessions).
[Running the usability study](../docs/usability-study.md) is the facilitator's
guide.

| Path | Purpose |
| --- | --- |
| `tasks/U1` to `tasks/U6` | Each task's participant prompt and starter files |
| `prepare.py` | Creates a participant's workspace, task order, and kit record |
| `check.py` | Checks a task folder against the task's success criteria |
| `sheet.csv` | The timing and scoring sheet's columns |
| `score.py` | Scores a completed sheet against the registered thresholds |
| `consent.md` | The consent note read to each participant |
| `results.md` | The results report template |

Reference solutions live in `tests/usability`, outside this kit, so they are
never handed to participants.
