# U1: Read a script

`order.botwork` is a script you have not seen before. Do not run it.

1. Write the lines you expect it to print, in order, one per line, in
   `answer.txt`. Put nothing else in that file.
2. Then tell the facilitator, out loud, why each `high` or `low` line appears,
   and what value the script logs last and why.

You may read the published Botwork documentation.
