# U2: Write and run a first script

Botwork is installed. Using only the published documentation, write a script
named `first.botwork` in this folder that:

- sets a variable `quantity` to 3 and a variable `price` to 4;
- calculates the product of `quantity` and `price`;
- logs the product.

Run it with Botwork. You are done when it prints `12` and exits successfully.
