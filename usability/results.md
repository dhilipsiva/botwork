# Usability results: ROUND

Copy this template for each round (original or retest) and fill it from the
scoring sheet and `score.py`.

- **Kit revision:** the `revision` from each workspace's `kit.json`.
- **Botwork build and documentation revision:**
- **Environment:** operating system, installation method, editor.
- **Dates and facilitator:**
- **Participants:** total, newcomers, experienced. Cohort definitions and any
  prior Botwork exposure.

## Results by task

Paste the per-task lines from `score.py`: unaided successes over attempts, for
all participants and for each cohort.

## Thresholds

Paste each threshold's verdict from `score.py`. Keep the sheet and the JSON
result with this report.

## Misunderstandings

For each recurring misunderstanding: the task, how many participants, what
they tried, and the documentation or syntax involved.

## Changes before the next round

Each change to the release, documentation, prompts, or materials, and which
tasks must be repeated with fresh participants. Original results stay
published beside any retest.

## Limitations

Cohort sizes, recruitment, and anything that departed from the procedure in
docs/usability-study.md.
